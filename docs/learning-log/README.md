# Learning log

One file per work session, named `YYYY-MM-DD-topic.md` (e.g. `2026-10-14-phase0-bringup.md`).
Start from `TEMPLATE.md`. Keep entries short — 20 minutes max, honest over polished.

Rules:
- One insight section is the core — no insight, no entry.
- "Still fuzzy" is the most valuable list you will write. Those items become your next prompts,
  exercises, or reading. Never leave an item there twice.
- Quiz questions are for future-you: write them while it's fresh, answer them a week later with the
  code closed.
- Link files with paths, so future-you can jump straight in.
